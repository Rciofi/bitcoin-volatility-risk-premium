\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This dissertation studies the Bitcoin volatility risk premium (BVRP), the
difference between the historical volatility over the following 30 days and
the implied volatility of Deribit's DVOL, using daily data from March
2021 to March 2026. The BVRP is negative on average ($-8.76$ percentage
points): implied volatility exceeds the volatility subsequently realized.
Linear and machine learning models have lower out-of-sample errors than the
historical mean, but the model confidence set does not separate them from it. The forecast BVRP does not predict
Bitcoin returns in this sample, either with a linear model or with a random
forest.

\vspace{0.5cm}
\noindent\textbf{Keywords:} Bitcoin; volatility risk premium; implied volatility; DVOL; return predictability; machine learning.
