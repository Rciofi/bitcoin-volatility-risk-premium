\par\smallskip
\footnotesize\textit{Nota sobre múltiplos testes}:
Aplicou-se a correção de Benjamini--Hochberg (FDR) para os seis horizontes
avaliados simultaneamente ($h = 1, 5, 10, 20, 30, 60$ dias).
Como nenhum valor-$p$ bruto se aproxima de $0{,}05$
(mínimo observado: $p = 0{,}241$ para $h = 1$),
a correção não altera as conclusões sobre a ausência de previsibilidade
linear do BVRP sobre os retornos futuros do Bitcoin.
Os valores-$p$ corrigidos por BH situam-se entre $0{,}91$ e $1{,}00$
para todos os horizontes.
