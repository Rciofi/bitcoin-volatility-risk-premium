# Bitcoin Volatility Risk Premium (BVRP)

Dissertação de mestrado sobre o Bitcoin Volatility Risk Premium (BVRP), com foco na análise empírica, modelagem econométrica e aplicação de machine learning para previsão de retornos.

## Objetivo

Avaliar o comportamento do BVRP e sua capacidade preditiva sobre retornos futuros do Bitcoin, utilizando:

- Modelos OLS  
- Modelos de Machine Learning (Random Forest, XGBoost, etc.)  
- Estratégias baseadas em regimes e quantis
