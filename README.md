# bitcoin-volatility-risk-premium
Dissertação de mestrado sobre Bitcoin Volatility Risk Premium: O objetivo geral desta dissertação é analisar, de forma quantitativa e abrangente, o Bitcoin Volatility Risk Premium (BVRP) e investigar sua capacidade preditiva para retornos futuros do Bitcoin em horizontes de curto e médio prazo, com ênfase na combinação entre métricas de volatilidad
